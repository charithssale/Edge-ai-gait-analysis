# Real-Time Walking Speed Estimation and Gait Analysis with Edge AI

## Overview

This project presents a real-time gait analysis and walking speed estimation system using ultrasonic sensors, ESP32-based edge computing, and machine learning.

The system collects distance measurements from ultrasonic sensors, extracts gait-related features, and classifies walking speed into different categories in real time.

## Features

* Real-time walking speed estimation
* Gait pattern analysis
* Edge AI deployment on ESP32
* Ultrasonic sensor-based data acquisition
* Machine learning classification
* Low-latency inference
* Wireless communication using LoRa

## Hardware

* ESP32 / LoRa32 Development Board
* HC-SR04 Ultrasonic Sensor
* Power Supply Module

## Software

* Arduino IDE
* Python
* TensorFlow / TensorFlow Lite
* Jupyter Notebook

## Results

* Classification Accuracy: 95%
* Real-time Edge Deployment
* Low Inference Latency
* Walking Speed Classification:

  * Slow
  * Normal
  * Fast
